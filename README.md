# Lucky Lu

适合两个人使用的自托管经期记录工具。网页、账号接口和 SQLite 数据库由同一个 Node.js 服务提供，适合部署在一台小型云服务器上。

## 已实现

- 账号注册、登录和 30 天 HttpOnly 会话
- scrypt 密码哈希、登录限速、输入校验和安全响应头
- 经期、经量、疼痛、症状、心情、睡眠与小记的云端同步
- 周期阶段与经期范围估算
- 基于最近完整周期中位数的预测、可信度与波动范围
- 周期历史、症状趋势和需要持续留意的重复信号
- 可设置提前提醒天数
- 每个账号独立的数据空间
- 一次性邀请链接（7 天有效），可选择只读或可编辑
- 空间所有者可随时移除共享成员
- 多设备冲突检测，避免静默覆盖较新的记录
- 旧版 `localStorage` 数据一键迁移、JSON 导入与导出
- Docker 数据卷持久化及健康检查

## 本地运行

需要 Node.js 22.5 或更高版本。

```bash
npm install
COOKIE_SECURE=0 TRUST_PROXY=0 npm start
```

打开 `http://localhost:3000`。首次使用时创建账号即可。

## Docker 运行

```bash
docker compose up -d --build
```

应用只监听宿主机 `127.0.0.1:3000`，应在前面配置 Caddy 或 Nginx，通过 HTTPS 域名对外提供服务。

## 两个人如何共享

1. 由记录者先创建账号。
2. 进入“我的设置 → 共享给信任的人”。
3. 选择“只读查看”或“可以记录和修改”，生成一次性邀请链接。
4. 对方打开链接并登录自己的账号，确认加入。
5. 对方可以在“账号与空间”中切换自己的空间与共享空间。

建议默认选择“只读查看”。经期数据属于敏感健康信息，只有在记录者明确同意后才应共享。

## 阿里云 ECS 部署

生产配置位于 `deploy/`。在服务器上解压项目后，从项目根目录执行：

```bash
./deploy/start-production.sh --app-only
curl -fsS http://127.0.0.1:3000/api/health
```

首次运行会创建仅限服务器读取的 `.env`，其中包含随机生成的 `SIGNUP_CODE`。该阶段仅在服务器本机的 `127.0.0.1:3000` 提供服务。账号与记录位于 `data/lulu.sqlite`，此目录绑定到容器，重建或重启容器不会清除数据。

部署包默认只包含程序，不包含本地 `data/` 中的账号和经期记录。若要迁移已有记录，需要另行备份并导入数据库。

`luckylu.top` 指向中国内地服务器时，先完成 ICP 备案。备案通过后，将域名的 A 记录指向服务器公网 IP，放通安全组及系统防火墙的 TCP 80、443（使用 HTTP/3 时还需 UDP 443），再执行：

```bash
./deploy/start-production.sh
docker compose --env-file .env -f deploy/docker-compose.prod.yml ps
```

Caddy 会申请并续期 HTTPS 证书，应用继续只监听本机 3000 端口。不要把 3000 端口对公网开放。注册时需使用 `.env` 中的访问码；只向要创建账号的人分享该码。

请定期对 `data/lulu.sqlite` 做一致性备份，并将备份放到另一台设备或云存储。更新前先备份数据库，再重建容器。服务器磁盘持久化不能替代异地备份。

当前 Vercel 静态部署无法运行这个后端，也不适合持久化 SQLite。完成云服务器和域名准备后，应将整个项目部署到服务器，而不是只上传 `dist` 目录。
